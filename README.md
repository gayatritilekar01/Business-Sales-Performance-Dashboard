# 📊 Business Sales Performance Dashboard

## 📌 Project Overview
This project is a **Business Sales Performance Dashboard** created using **Microsoft Power BI** as part of **Future Intern – Data Science Internship Task 1**.

The dashboard provides an interactive view of business sales performance and helps analyze sales, profit, products, customers, and sales trends.

## 🎯 Objective
The main objective of this project is to analyze business sales data and present meaningful insights through an interactive and easy-to-understand dashboard.

## 🛠️ Tools Used
- Microsoft Power BI
- Power Query
- Data Cleaning
- Data Visualization
- Data Analysis

## 📈 Dashboard Features
- Total Sales Analysis
- Total Profit Analysis
- Product-wise Sales Performance
- Monthly Sales Trend
- Customer Analysis
- Interactive Slicers and Filters
- Key Business Insights
- ## 🔍 Key Insights
- Identified the top-performing products based on sales.
- Analyzed monthly sales trends to understand business performance over time.
- Compared sales and profit to evaluate overall performance.
- Used interactive slicers to analyze the data efficiently.

## 💡 Business Recommendations
- Focus more on high-performing products to increase overall revenue.
- Monitor low-performing products and improve their sales strategy.
- Use monthly sales trends to plan future sales and promotional activities.
- Regularly track sales and profit KPIs for better business decisions.
