# 📊 Business Sales Performance Dashboard

## 📌 Project Overview
This project is a **Business Sales Performance Dashboard** created using **Microsoft Power BI** as part of **Future Intern – Data Science Internship Task 1**.

The dashboard provides an interactive view of business sales performance and helps analyze sales, profit, products, customers, and sales trends.

## 🎯 Objective
The main objective of this project is to analyze business sales data and present meaningful insights through an interactive and easy-to-understand dashboard.

## 🛠️ Tools Used
- Microsoft Power BI
- Power Query
- Data Cleaning
- Data Visualization
- Data Analysis

## 📈 Dashboard Features
- Total Sales Analysis
- Total Profit Analysis
- Product-wise Sales Performance
- Monthly Sales Trend
- Customer Analysis
- Interactive Slicers and Filters
- Key Business Insights
